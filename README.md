# Мой путь во Flutter

Приложение-самопрезентация Богдана Тарана для Android и iOS на Flutter 3.47.6 / Dart 3.13.5. Дополнительно собирается для Web, чтобы быстро просматривать интерфейс.

## Запуск

```sh
flutter pub get
flutter devices
flutter run
```

Для Android:

```sh
flutter build apk --release
```

Для iOS Simulator без подписи:

```sh
flutter build ios --simulator --no-codesign
```

Для физического iPhone необходимо выбрать свою команду подписи в Xcode. Android release в этом демонстрационном проекте использует стандартную отладочную подпись; перед публикацией её нужно заменить собственной.

## Экраны и поведение

Реализованы 11 экранов: приветствие, обзор, профиль, важность выбора, профессия, обязанности, навыки, обучение, карьерный рост, плюсы и минусы, выбор Flutter.

Нижняя навигация повторяет порядок экспорта: **Обзор → Профессия → Навыки → Мой путь → Профиль**. Вкладки сохраняют вложенный экран и положение прокрутки. Повторное нажатие активной вкладки возвращает на её основной экран. Вложенные страницы имеют возврат назад; переходы между разделами переключают соответствующую вкладку.

- «Стек?» и «Почему?» из профиля ведут на соответствующие дополнительные страницы раздела «Мой путь», как показано активной вкладкой в экспорте.
- Все три акцентных хобби открывают окна с иллюстрациями и описанием. Окна закрываются крестиком, жестом вниз или нажатием на затемнение.
- Каждую из шести платформ каталога можно добавить один раз в любом порядке. Счётчик хранится при смене вкладки. После добавления шестой платформы появляется закрываемое окно подтверждения в оформлении экспорта. Повторное добавление исключено.
- На странице обязанностей нажатие меняет акцентную карточку, последняя карточка открывает навыки.
- Навыки → обучение → карьерный рост связаны кнопками.
- Первые три ступени роста первоначально свёрнуты, раскрываются и выделяются при нажатии. Последняя тёмная карточка сохраняет цвет и открывает плюсы и минусы.
- Кнопки выбора Flutter ведут к экрану «Один стек. Много платформ.»; оттуда можно вернуться к обзору.

## Дизайн и адаптивность

Основа — предоставленный архив «Экраны приложения.zip». Все тексты, цвета, карточки, фотография и иллюстрации перенесены из экспорта. Полные скриншоты экранов не используются вместо интерфейса: тексты, кнопки, сетки и карточки — обычные Flutter-виджеты. Фотография, иллюстрации и значки выделены из предоставленных PNG без перерисовки; их исходное разрешение ограничено экспортом 1×.

Roboto включён локально в начертаниях Regular, Medium, Bold и Black. Сетевых запросов для шрифтов и изображений нет. Интерфейс русскоязычный.

Цвета находятся в `lib/core/theme/app_theme.dart`: фон, светлые карточки, основной текст, лимонный акцент и отдельный фон приветствия.

На телефоне каталог использует две колонки, на широком экране — три. Контент ограничен шириной 720, нижняя навигация — 560. Длинные страницы прокручиваются, учитываются безопасные области устройства и увеличенный системный текст. Небольшие отличия положения элементов от исходных PNG зависят от безопасных областей конкретного устройства и размера текста.

## Архитектура

- `lib/app`: приложение, локализация, go_router, оболочка вкладок.
- `lib/core/theme`: тема и цветовые токены.
- `lib/features/presentation/domain`: независимые от Flutter модели, содержимое и правила каталога.
- `lib/features/presentation/presentation/view_models`: Riverpod Notifier для каталога, выбранной обязанности и раскрытия ступеней роста.
- `lib/features/presentation/presentation/views`: View, общие карточки, профиль и модальные окна.

Использована MVVM с разделением domain/presentation. Отдельный data-слой не добавлен, поскольку у этого приложения нет API, базы данных и авторизации. Контент локальный; состояние интерактивных элементов живёт в памяти до перезапуска приложения.

## Проверки

```sh
flutter analyze
flutter test
```

10 функциональных тестов проверяют правила каталога, независимое раскрытие, все маршруты, ширины 320/393/900, увеличение текста в 1,6 раза, сохранение вкладок, три окна хобби, шестой товар и основные цепочки переходов.

Для отрисовки контрольных изображений:

```sh
flutter test --update-goldens --dart-define=CAPTURE=true
```

Этот режим выполняет 21 тест, включая отдельную отрисовку 11 экранов, и сохраняет изображения в `review/`. Рендеры проверены визуально; графические ресурсы проверены отдельно. Системная строка состояния в тестовых изображениях не рисуется.

Выполнены сборки Android APK, iOS Simulator и Web. Приложение установлено и запущено на iPhone 17 Pro Simulator с проверкой приветствия и навигации. На физическом Android/iPhone и в магазинах приложений проверка не выполнялась.
